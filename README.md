# Hospital Management System

Full-stack application with Spring Boot backend and React frontend.

## Modules

- Outpatient & Inpatient Management
- Pharmacy Stock + Email Alerts
- Inpatient Billing
- Lab Results Management
- Room Allocation

## Run Instructions

### Backend
```bash
cd backend
mvn spring-boot:run
```

### Frontend
```bash
cd frontend
npm install
npm start
```

Make sure PostgreSQL is running and credentials are correct in `application.yml`.
